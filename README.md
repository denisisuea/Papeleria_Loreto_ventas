# Sistema de Gestión de Ventas e Inventario

## Módulo seleccionado
Registro de ventas.

## Descripción
El módulo permitirá registrar las ventas realizadas, seleccionar los productos,
ingresar las cantidades correspondientes, calcular el total de la venta y
actualizar el inventario de acuerdo con los productos vendidos.

## Stack tecnológico
- Python
- Flask
- Git
- GitHub
- GitHub Actions

## Flujo de ramas

El proyecto utilizará un flujo de trabajo basado en GitHub Flow.

- `main`: contendrá la versión estable del módulo.
- `feature/*`: se utilizará para desarrollar nuevas funcionalidades.
- Los cambios realizados en las ramas feature serán integrados a main
  mediante Pull Request.

Ejemplo:

feature/registro-venta
